PREETI FONT SETUP (OFFLINE)
===========================
Replace `Preeti.ttf` in this `fonts/` folder with your official `Preeti.ttf` file.
Because `css/styles.css` loads `@font-face { font-family: 'Preeti'; src: url('../fonts/Preeti.ttf') format('truetype'); }`,
every Nepali (Preeti) text box, print sheet, and PDF export will automatically render authentic Preeti glyphs offline!

NOTE: The bundled `Preeti.ttf` is a valid placeholder TTF so the browser does not throw font-loading errors out of the box.
